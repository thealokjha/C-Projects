# CLI Utility Toolkit

A simple, interactive command-line interface (CLI) toolkit written in C. This tool provides basic mathematical and logic operations directly through a terminal-based menu.

---

## Features

- **Sum:** Calculates the addition of two integer numbers.
- **Max:** Determines the maximum value between two numbers.
- **Min:** Determines the minimum value between two numbers.
- **Even/Odd Check:** Checks whether an input number is even or odd.
- **Interactive Menu:** Loop-driven console navigation with clean user input prompts.
